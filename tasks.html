Прогресс разработки — MVP

Снимок на 2026-08-02 · по сути сделанного, не по числу файлов

Разработчик передал в репозиторий рабочий MVP учётной системы: backend, мобильная форма отчёта водителя, административная панель.

Что работает

  • Вход через Google, собственные сессии с защитой от кражи токена, мгновенный отзыв доступа
  • Три роли (водитель / бухгалтер / админ) с разграничением прав
  • Мобильная форма отчёта водителя: машина, заправки, фото чека в приватное хранилище, черновик не теряется
  • Административная панель: рейсы, расходы, пользователи, автомобили, сводка прибыли/убытка за период
  • Автоматические тесты на ключевую логику (доступ, права, безопасность)

Что ещё не сделано

  • Прод и тестовое окружение пока не разделены на сервере
  • Шифрование (HTTPS) не настроено — без него вход через Google не заработает на реальном адресе. Сервер, домен и DNS для этого уже готовы
  • Автоматического деплоя, резервного копирования базы и мониторинга пока нет
  • Первого администратора приходится заводить вручную (не через интерфейс)
