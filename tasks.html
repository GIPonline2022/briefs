Прогресс разработки — MVP

Снимок на 2026-08-05 · по сути сделанного, не по числу файлов

Прод и дев-окружения развёрнуты на боевом сервере и работают по HTTPS: backend, мобильная форма отчёта водителя, административная панель, хранилище фото чеков.

Что работает

  • Вход через Google в боевом режиме, собственные сессии с защитой от кражи токена, мгновенный отзыв доступа
  • Три роли (водитель / бухгалтер / админ) с разграничением прав
  • Мобильная форма отчёта водителя: машина, заправки, фото чека, черновик не теряется
  • Административная панель: рейсы, расходы, пользователи, автомобили, сводка прибыли/убытка за период
  • Просмотр и загрузка фото чеков в проде работают через собственное приватное хранилище
  • Сайт и админка работают по HTTPS, сертификат продлевается автоматически
  • Отдельное тестовое окружение на том же сервере — можно проверять изменения до прода
  • Автодеплой: пуш обновляет нужное окружение через самостоятельный раннер на сервере
  • Автоматический снэпшот базы перед каждым применением миграций плюс ежедневные резервные копии
  • Автоматическая проверка (тесты, линт, сборка) на каждое изменение кода
  • Вход на сервер только по ключам, парольный вход отключён
  • Черновик документа по эксплуатационной безопасности — ждёт вычитки PO

Что ещё не сделано

  • Обязательная проверка перед выкладкой в прод (branch protection) — упёрлась в тарифный вопрос GitHub, решение за PO
  • Внешнего мониторинга (кроме базового) и резервного копирования базы за пределами сервера пока нет
  • Первого администратора приходится заводить вручную (не через интерфейс)
